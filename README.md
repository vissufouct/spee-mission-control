# SPEE Helpdesk Analysis

Área de trabalho do projecto SPEE, incluindo análises, documentação, protótipos e o frontend local para exploração e validação da experiência do Mission Control do Docente e do Estudante.

Frontend publicado: [SPEE Mission Control](https://vissufouct.github.io/spee-mission-control/).

## Organização

- `frontend/`: aplicação React/TypeScript e respectiva documentação técnica;
- `output/`: PRDs, mockups e outros resultados de desenho;
- `outputs/`: artefactos de análise e entregáveis anteriores;
- `chats/`: materiais de apoio às análises;
- documentos e scripts na raiz: backlog, relatórios e ferramentas de geração.

## Executar o frontend

Consultar [frontend/README.md](frontend/README.md) para instalar as dependências, iniciar a aplicação e executar as verificações.

O ponto de partida local fica disponível em `http://127.0.0.1:5173/` depois de executar `npm run dev` dentro de `frontend/`.
