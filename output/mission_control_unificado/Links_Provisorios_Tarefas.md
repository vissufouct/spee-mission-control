# Links provisórios das tarefas — demonstração SPEE

Todos os endereços seguintes são provisórios e foram fornecidos para a demonstração; a disponibilidade e o acesso autenticado não estão garantidos.

## Como actualizar

Edite a coluna URL e, se necessário, o texto do botão. Preserve os IDs das tarefas e a estrutura da tabela. Cada linha representa um botão; várias linhas com o mesmo ID criam vários botões no popup. Depois peça: «Aplique os links do ficheiro Links_Provisorios_Tarefas.md ao protótipo».

O script `python3 scripts/roteiro/sync-task-links.py` valida a tabela e actualiza os dois exemplos JSON e as ligações do cenário docente. O browser não lê este Markdown directamente. É necessário voltar a gerar/publicar o frontend para actualizar a versão pública. Os registos locais mantêm estados, respostas e submissões; os links e textos de orientação são actualizados pelo repository.

Todos os botões abrem um novo separador. Abrir um link não confirma a conclusão da tarefa. Os parâmetros dos URLs devem ser mantidos exactamente, incluindo `&`. Não inserir credenciais nos links.
